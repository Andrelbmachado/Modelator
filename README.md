# Modelator 🧊

**Um "segundo Blender" agent-friendly: um modelador 3D pronto para ser usado por IA.**

Modelagem, edição e gerenciamento 3D para macOS e iPad (chips M), com escaneamento LiDAR no iPhone — e com uma API pensada para que agentes de IA consigam modelar junto com você.

## Status
Base em SwiftUI: estrutura de app (`Sources/App`), cena 3D (`Sources/Engine3D`), visualização LiDAR (`Sources/Lidar`), modos de render e barras laterais personalizáveis (`Sources/UI`). Detalhes em [Informacoes projeto.txt](Informacoes%20projeto.txt).
